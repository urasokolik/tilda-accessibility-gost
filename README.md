# Tilda Accessibility Widget (ГОСТ Р 52872-2019 / WCAG 2.1)

Автономный встраиваемый модуль версии для слабовидящих для сайтов на конструкторе **Tilda Publishing**, полностью соответствующий требованиям государственного стандарта **ГОСТ Р 52872-2019** и международным рекомендациям **WCAG 2.1**.

Решение разработано с учетом архитектурных особенностей Tilda и обеспечивает корректное отображение как стандартных библиотечных блоков, так и сложных **Zero Blocks (T396)** без деформации сетки и наложения элементов.

---

## 🌟 Основные возможности

### 1. Цветовые контрастные схемы по ГОСТ
Модуль поддерживает 5 стандартизированных тем оформления с автоматическим переопределением цветов фона и шрифтов:
* **Черным по белому** (классический высококонтрастный светлый режим)
* **Белым по черному** (инвертированная темная тема)
* **Темно-синим по голубому** (снижает утомляемость глаз)
* **Коричневым по бежевому** (мягкая теплая гамма)
* **Черным по желтому** (специальный высококонтрастный режим)

### 2. Масштабирование шрифта с защитой Zero Blocks
* 3 градации размера: `100%`, `120%`, `140%`
* **Zero Block Fix:** Для блоков T396 с абсолютными координатами (`position: absolute`) используется пропорциональное масштабирование через `zoom`, сохраняющее точную геометрию холста и предотвращающее наезд текстов друг на друга.

### 3. Управление медиаконтентом
* `Вкл` — отображение цветных изображений
* `Ч/Б` — монохромный режим (фильтр градаций серого)
* `Выкл` — скрытие изображений без схлопывания каркаса верстки

### 4. Типографика и интервалы
* Переключение гарнитуры: без засечек (`Arial`) / с засечками (`Times New Roman`)
* Межстрочный интервал (интерлиньяж): `1.4x`, `1.7x`, `2.0x`
* Межбуквенный интервал (кернинг): `стандартный`, `+1px`, `+2px`

### 5. Синтезатор речи (Web Speech API)
* Встроенное голосовое озвучивание текста на русском языке
* Чтение фрагментов по клику или выделению курсором
* Визуальная подсветка воспроизводимого текста и плавающая кнопка остановки речи

### 6. Навигация и сохранение состояния
* Компактная плавающая кнопка вызова виджета
* Поддержка активации через якорные ссылки `#bvi`
* Сохранение пользовательских настроек в `localStorage`
* Доступность с клавиатуры (фокус, `Tab`, `Enter`)

## 📁 Структура проекта

* `bvi-tilda.js` — ядро скрипта панели и управления состоянием
* `bvi-tilda.css` — стили виджета, контрастных схем и адаптации Tilda
* `tilda-head-bundle.html` — готовый бандл для быстрой вставки в Head Code проекта Tilda

---

## 🚀 Быстрый старт на Tilda

1. Перейдите в **Настройки сайта** $\rightarrow$ вкладка **«Ещё»** $\rightarrow$ поле **«HTML-код для вставки внутрь тега `<head>`»**.
2. Вставьте код из файла `tilda-head-bundle.html`.
3. Сохраните изменения и переопубликуйте страницы сайта.
